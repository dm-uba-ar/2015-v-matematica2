# **Régimen de aprobación**

- Habrá dos exámenes parciales y un recuperatorio para cada uno de ellos al final del curso. En particular, no se podrá recuperar el mismo examen dos veces.
- El alumno puede, aún habiendo aprobado el parcial, rendir el recuperatorio correspondiente para modificar la nota. En este caso su parcial aprobado caduca, como si no lo hubiera rendido.
- La nota final será el promedio de las notas obtenidas en los exámenes aprobados.
